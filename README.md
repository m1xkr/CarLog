# Бортжурнал

Учёт заправок и расходов на автомобиль: веб-приложение (PWA) для iPhone и любого браузера.
Работает без интернета, данные синхронизируются через Яндекс Диск.

**Адрес:** https://m1xkr.github.io/CarLog/

## Возможности

- Импорт из Car Expenses: резервная копия `ce_db_backup_*.db` (все машины сразу, читается через sql.js с CDN)
  или текстовый экспорт CE v.30.x; повторный импорт не создаёт дублей.
- Готовый справочник работ с интервалами (масло, фильтры, свечи, ОСАГО…); при добавлении расхода —
  частые работы этой машины одним нажатием и полный список с поиском; экран «Работы и интервалы».
- Заправки: литры, цена и сумма (любые два поля, третье считается само), расход по методу «полный бак».
- Расходы по категориям, с разбивкой на запчасти и работу, поиск и фильтр.
- События обслуживания: интервал по пробегу и/или времени (масло — 7 500 км или 1 год), разовые сроки.
  Следующий срок считается от последнего расхода с этим видом работ — новая запись продлевает событие сама.
  Просрочено / скоро / в норме, оценка даты по среднему пробегу, экспорт сроков в Календарь (.ics).
  Интервалы и история переносятся из Car Expenses.
- Запчасти с ресурсом (шины, аккумулятор, колодки): установка и снятие, пробег копится только пока деталь стоит,
  износ по пробегу и сроку службы, покупка сразу попадает в расходы.
- Отчёт по обслуживанию для продажи: данные машины и VIN, регламентные работы, запчасти, хронология работ
  по выбранным категориям, суммы по желанию; печать в PDF или отправка файлом.
- Статистика: траты по месяцам и годам, стоимость километра, график расхода топлива, сводка по годам.
- Синхронизация через Google Диск (скрытая папка приложения, без прокси) или Яндекс Диск: файл `carlog.json`,
  слияние по времени правки каждой записи.
- Резервная копия (JSON) и выгрузка таблицы (CSV для Excel/Numbers).

## Установка на iPhone

Открыть адрес в Safari → «Поделиться» → «На экран „Домой“».

## Google Диск

1. https://console.cloud.google.com → новый проект → «APIs & Services» → включить **Google Drive API**.
2. «Google Auth Platform»: брендинг (название «Бортжурнал», почта), аудитория **External**, доступ к данным —
   права `…/auth/drive.appdata` и `email` (оба не требуют проверки Google), затем **Publish app**.
3. «Clients» → «Create client» → **Web application**: Authorized JavaScript origins `https://m1xkr.github.io`,
   Authorized redirect URIs `https://m1xkr.github.io/CarLog/`.
4. Client ID вписать в `GOOGLE_CLIENT_ID` в `js/config.js` (или ввести в приложении: «⚙» → «Синхронизация»).

Google выдаёт браузерным приложениям вход на час; приложение продлевает его само коротким переходом
на Google без вопросов (`prompt=none`), не чаще раза в 2 минуты и не во время заполнения формы.

## Яндекс Диск

1. На https://oauth.yandex.ru создать приложение: платформа «Веб-сервисы», Redirect URI
   `https://m1xkr.github.io/CarLog/` (и запасной `https://oauth.yandex.ru/verification_code`),
   доступ «Яндекс Диск REST API → Доступ к папке приложения на Диске».
2. ClientID прописан в `js/config.js` — пользователям вводить ничего не нужно.
3. Если файловые серверы Диска не разрешают запросы со страниц (ошибка CORS), нужен прокси:
   `proxy/yandex-cloud-function.js` (Yandex Cloud Functions, Node.js 18+, публичная функция) или
   `proxy/cloudflare-worker.js`. Адрес прокси — в `YANDEX_PROXY` в `js/config.js` или в приложении
   («⚙» → «Яндекс Диск»). Приложение само переходит на прокси только для тех серверов, что не ответили напрямую.
   Кнопка «Проверить связь с Диском» показывает, какой шаг не проходит.

## Устройство

Без сборки и зависимостей: `index.html`, `css/app.css`, ES-модули в `js/`:

| Файл | Назначение |
|---|---|
| `js/store.js` | Модель данных, localStorage, слияние копий |
| `js/ce-import.js` | Разбор экспорта Car Expenses |
| `js/ce-db.js` | Чтение базы Car Expenses (.db) |
| `js/catalog.js` | Справочник работ, миграции, слияние дублей |
| `js/stats.js` | Расход топлива, сводки, категории |
| `js/events.js` | События ТО: сроки, остатки, календарь |
| `js/parts.js` | Запчасти: пробег в установке, износ |
| `js/report.js` | Отчёт по обслуживанию для покупателя |
| `js/gdrive.js` | OAuth и API Google Диска |
| `js/yadisk.js` | OAuth и API Яндекс Диска |
| `js/sync.js` | Синхронизация |
| `js/app.js` | Интерфейс |
| `sw.js` | Офлайн-кэш (при обновлении менять `VERSION`) |
